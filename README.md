# DATA-EXPLORATORY-ANALYSIS-FOR-CREDIT-CARD-DATA
 📌 Project Overview
This project performs **Exploratory Data Analysis (EDA) on credit card data** to understand customer spending and repayment behavior. The analysis covers customer acquisition, transactions, repayments, profitability, product performance, and city-wise spending patterns.
 🎯 Objectives
* Clean and preprocess credit card data
* Analyze customer spending and repayment behavior
* Calculate monthly spending, repayment, and bank profit
* Identify top-performing products and customers
* Analyze spending across cities and age groups
* Identify monthly and yearly spending trends
* Visualize important business insights
* Build a dynamic Python function to identify top 10 customers
 📂 Dataset
The dataset contains three major components:
* **Customer Acquisition** – Customer details and credit limits
* **Spend** – Credit card transaction information
* **Repayment** – Customer repayment information
 🔍 Key Analysis
The project answers questions such as:
* Number of distinct customers and categories
* Average monthly spend and repayment
* Monthly bank profit at a 2.9% interest rate
* Top 5 product types
* City with maximum spending
* Age group with highest spending
* Top 10 customers based on repayment
* City-wise and product-wise yearly spending
* Monthly spending trends and seasonality

 📊 Visualizations
The project includes visual analysis of:
* Monthly total spend by city
* Yearly air-ticket spending
* Monthly spending by product
* City-wise and product-wise spending trends
⚙️ Technologies Used
* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook
🚀 Dynamic Analysis Function
A user-defined Python function allows users to specify:
* Product: **Gold / Silver / Platinum**
* Time period: **Yearly / Monthly**
The function then identifies the **top 10 customers in each city based on repayment amount**.
💡 Business Value
The analysis demonstrates how credit card data can be used to understand customer behavior, identify spending patterns, evaluate profitability, and support data-driven decisions related to customer service, collections, and suspicious activity.
